Compass Clean

A local desktop app that strips embedded metadata from documents and images, then writes back only the fields you choose. Nothing leaves your machine.

Download for Windows (v1.1.0)
Also available: macOS, Linux & all releases

What it strips

  • DOCX / PPTX / XLSX — author, dates, company, and per-edit-session fingerprints
  • PDF — Title, Author, Subject, Keywords, Creator, Producer
  • PNG / JPG / WebP / TIFF — EXIF/IPTC/XMP, embedded AI generation prompts, and C2PA content-credential manifests (with verified removal)

What it is / is not

Is: an offline tool to remove identifying metadata before sharing, saving a cleaned copy and never touching the original.
Is not: a watermark remover — it does not defeat invisible pixel watermarks (e.g. SynthID). It is not a cloud service.
